## What I'm working on

### [SatyaPath](https://github.com/khandelwalaryan2307-wq/SatyaPath)

An AI-assisted application validation and regulatory compliance prototype created for **Smart India Hackathon 2026**. It brings application intake, evidence-linked checks, reviewer decisions, and audit history into one workspace.

- Built with **React, TypeScript, FastAPI, Python, and SQLAlchemy**
- Includes deterministic synthetic demo scenarios and configurable validation rules
- Designed to keep findings explainable and reviewer decisions transparent

> SatyaPath is a hackathon prototype. Its institutional data and source checks are synthetic; it does not connect to live AICTE systems or make official regulatory decisions.

## How I like to build

- Start with a real workflow and make the important actions work end to end.
- Keep interfaces clear, responsive, and easy to scan.
- Make automated checks explain what they found and where the evidence came from.
- Be honest about limitations, especially when a prototype uses synthetic data.
